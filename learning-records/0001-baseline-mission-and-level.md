# 0001 · Mission และระดับเริ่มต้นของผู้เรียน

- **วันที่** 2026-10-24
- **ประเภท** Baseline record (ข้อมูลตั้งต้น ใช้คำนวณ zone of proximal development)

## สิ่งที่จด

- **Mission** (ตอบเองโดยผู้เรียน): ตัดสินใจว่าจะใช้ Controller-based หรือ Minimal API กับโปรเจกต์จริง
- **ระดับ** (ตอบเองโดยผู้เรียน): เพิ่งเริ่มเรียน C#/.NET
- **สิ่งที่ทำได้แล้วจากหลักฐานโค้ด** (ประเมินจาก TodoApiV2 ที่เขียนไว้):
  - เขียน CRUD controller + EF Core + DTO ได้ตามแบบ/ตาม tutorial
  - ใช้ async/await เป็น (ยังไม่เข้าใจเชิงลึก)
  - เข้าใจเบื้องต้นเรื่อง ForeignKey/Navigation property (มี comment อธิบายในโค้ด)
- **สิ่งที่ยังไม่รู้ (สมมติจาก level)**: DI container ทำงานอย่างจริงจัง, middleware pipeline, model binding, ทำไม controller ถึงถูก new ใหม่ทุก request

## ผลต่อการสอน

- ZPD ตอนนี้: **อ่านและอธิบายโค้ดที่ตัวเองเขียนอยู่แล้วให้เข้าใจกลไก** ยังไม่ใช่เขียนของใหม่ยากๆ
- บทที่ 1 (request lifecycle) ถือว่าอยู่ใน ZPD — ใช้โค้ดจริงที่คุ้นเคยเป็นสื่อ
- บทเรียนทุกบทต้องผูกกับ mission ขั้นสุดท้าย: จบคอร์สต้อง **ตัดสินใจเลือกสไตล์ให้โปรเจกต์จริงได้**
