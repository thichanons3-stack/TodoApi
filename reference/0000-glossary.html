Glossary — คำศัพท์ที่ใช้ในคอร์สนี้

ใช้คำเหล่านี้ให้ตรงกันทุกบท ถ้าเจอบทเรียนใช้คำนอกเหนือจากนี้ = เพิ่มลงที่นี่ก่อน

คำความหมาย (ฉบับสั้น)พบใน
Kestrelweb server ที่มาพร้อม .NET รับ/ส่ง HTTP bytesบทที่ 1
Pipeline / ท่อลำดับ middleware ที่ request ต้องผ่านก่อนถึง endpointบทที่ 1
Middlewareด่านทำงานกับ request/response ก่อนหรือหลังส่งต่อ (next) เช่น UseHttpsRedirectionบทที่ 1
Routingจับคู่ HTTP method + URL เข้ากับ endpointบทที่ 1
Endpointจุดจบที่ request ถูกประมวลผล (เช่น หนึ่ง action ใน controller)บทที่ 1
Controllerคลาสที่สืบทอด ControllerBase รวม action เป็นกลุ่มตามเรื่องบทที่ 1
Actionเมธอดใน controller ที่รับ request หนึ่งๆบทที่ 1
DI (Dependency Injection)กลไก "ยัดของที่ขอลง constructor" จาก container ที่ลงทะเบียนไว้บทที่ 1
Scopedอายุของ service — หนึ่ง instance ต่อหนึ่ง requestบทที่ 1
Singletonอายุของ service — หนึ่ง instance ตลอดชีพแอปบทที่ 1
Transientอายุของ service — สร้างใหม่ทุกครั้งที่ถูกขอบทที่ 1
DTO (Data Transfer Object)คลาสรูปทรงข้อมูลที่ใช้รับ/ส่งแทน entity จริง เช่น TodoItemDTOบทที่ 1
EF CoreORM — แปลง C# เป็น SQL ให้บทที่ 1
DbContextประตูต่อ database หนึ่งต่อหนึ่ง connection/scope เช่น TodoDbบทที่ 1
OpenAPIมาตรฐานเอกสารบรรยาย API — เครื่องมืออย่าง Swagger UI อ่านจากเอกสารนี้บทที่ 1
Boilerplateโค้ดพิธีรีตองที่ต้องเขียนซ้ำๆ แม้ไม่ใช่หัวใจของงานบทที่ 3 (เร็วๆ นี้)
Genericsปลอก <T> ที่รับ "ชนิดข้อมูล" เป็นพารามิเตอร์ เช่น List<TodoItem>บทที่ 2
Task / async / awaitใบรับฝากผลลัพธ์ + รอแบบไม่บล็อกเธรด — await ต้องอยู่ในเมธอด asyncบทที่ 2
Attributeป้าย [...] ติดคลาส/เมธอด ให้ framework เป็นคนอ่าน เช่น [HttpGet]บทที่ 2
Constructorเมธอดพิเศษใช้สร้างออบเจกต์ — DI ใช้เป็นประตูยัดของบทที่ 2
Nullable reference typeชนิด + ? = ยอมรับ null ให้ compiler เตือนก่อนพังตอนรันบทที่ 2
Model bindingกลไกแปลง HTTP request (URL/body/header) เป็นพารามิเตอร์เมธอดบทที่ 4 (เร็วๆ นี้)
Minimal APIสไตล์สร้าง endpoint ด้วย app.MapGet(...) + route handler ไม่มีคลาส/attribute — Microsoft แนะนำสำหรับโปรเจกต์ใหม่บทที่ 3
Route handlerเมธอด/lambda ที่ถูกเรียกเมื่อเส้นทางตรง — รับ parameter ที่ binding เติมให้บทที่ 3
Parameter bindingกลไกเติมค่าให้ parameter ของ handler จาก route/query/body/header/DIบทที่ 3
Route groupMapGroup("/prefix") — รวม endpoint ที่มีเส้นทางฐานเดียวกัน (แทน [Route] ของ controller)บทที่ 3
IResult / TypedResultsผลลัพธ์ HTTP ที่ระบุสถานะ+เนื้อหาตรงๆ เช่น TypedResults.Ok(x) = 200 + JSONบทที่ 3
Lambda expressionฟังก์ชันแบบสั้น (x) => ... ที่ใช้เป็น route handler ได้บทที่ 3
AmbiguousMatchExceptionข้อผิดพลาดตอนมีสอง endpoint แย่งเส้นทางเดียวกัน (ได้ 500)บทที่ 3
