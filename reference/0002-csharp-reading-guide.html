C# Cheat Sheet — แปลง syntax เป็นภาษาไทย

สรุปอัดแน่นจาก บทที่ 2 — ทุกตัวอย่างดึงจากโค้ดจริงในโปรเจกต์ TodoApiV2

1 · Generics — ปลอกใส่ชนิด

ในโค้ดอ่านว่า
DbSet<TodoItem>"ตาราง TodoItems ในฐานข้อมูล" — ชนิดข้างในบอกว่าเก็บอะไร
List<TodoItem>"รายการเก็บ TodoItem เท่านั้น" — ใส่อย่างอื่น compiler ขึ้นแดง
Task<T>"ใบรับฝากที่จะมี T มาให้ทีหลัง"
DbContextOptions<TodoDb>"ตั้งค่าสำหรับ TodoDb ตัวนี้โดยเฉพาะ"

2 · async / await / Task — รอแบบไม่บล็อก

public async Task<ActionResult<TodoItemDTO>> GetTodoItem(int id)   ← "รอทีหลัง คืนใบรับฝาก"
{
    var todo = await _context.TodoItems.FindAsync(id);              ← "รอตรงนี้ แต่เธรดว่างไปทำอื่นได้"
    ...
}
  • async = เปิดใช้ await ได้ในเมธอดนี้ · ไม่มี async = ใช้ await ไม่ได้
  • Task = ใบรับฝากไม่มีค่า · Task<T> = ใบรับฝากที่สัญญาว่าจะมี T
  • ลืม await = bug คลาสสิก — โค้ดจะรีบวิ่งต่อทั้งที่ผลยังไม่มา
  • ตาม convention: เมธอด async ควรลงท้ายด้วย Async (เช่น ToListAsync)

3 · Attributes — ป้ายที่ framework อ่าน

ป้ายใครอ่านอ่านเมื่อไร
[ApiController]MVCตอนเริ่ม — เปิด model binding/validation อัตโนมัติ
[Route("api/[controller]")]Routingตอนจับคู่ URL (บทที่ 1)
[HttpGet("{id}")]Routingตอนจับคู่ URL + method
[Required] [StringLength(100)]Model validationตอนรับ body เข้ามา — ไม่ผ่าน = ตอบ 400 ให้เอง

4 · Constructor + readonly

private readonly TodoDb _context;         // ตั้งครั้งเดียวตอนสร้าง ห้ามเปลี่ยนทีหลัง
public TodoItemsController(TodoDb context) // ประตูเดียว — DI ยื่น context ใส่ให้ (ทุก request ใหม่)

5 · Nullable — เครื่องหมาย ?

public string? Title      // string ที่ยอมรับ null (มาจาก <Nullable>enable</Nullable> ใน .csproj)
public DateTime? DueDate  // DateTime ที่ยอมรับ null
  • ใช้ค่าที่ "อาจ null" โดยไม่เช็ค → compiler เตือน → ถ้าฝืนรัน = NullReferenceException
  • Pattern ในโค้ดคุณ: if (x == null) return NotFound(...); เช็คก่อนใช้เสมอ

6 · Syntax เล็กๆ ที่เหลือ

เห็นอ่านว่า
var x = ...ให้ compiler เดาชนิดจากขวา — ยัง type-safe เต็มร้อย
{ get; set; }property ของคลาส อ่าน/เขียนได้
=> Set<TodoItem>();expression-bodied member — เมธอดหนึ่งบรรทัดแบบสั้น
new TodoItemDTO(todo)เรียก constructor — แปลง entity เป็น DTO (รูปทรงที่จะส่งออก)
is null / == nullเช็คว่าค่าว่างไหม — controller คุณใช้ทั้งสองแบบ
